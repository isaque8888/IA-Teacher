# IA-Teacher
Um aplicativo para aprender a programar em Python utilizando IA como tutora.

O AI Teacher é um aplicativo voltado a pessoas que estão começando a aprender programação, com foco inicial em Python. A proposta combina exercícios gerados por inteligência artificial, correção automatizada, orientação contextualizada e acompanhamento do desempenho. O objetivo é ajudar o estudante a compreender os problemas e construir suas próprias soluções, em vez de apenas receber respostas prontas.
